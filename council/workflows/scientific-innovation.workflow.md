# Workflow: Scientific Innovation

Use for invention, research direction, novel architecture, ML/statistical design, or physics-heavy
work.

1. Orchestrator defines target outcome and constraints.
2. Scout gathers local/project evidence and primary sources where needed.
3. Skeptic separates known facts, assumptions, and hypotheses.
4. Planner creates 2-4 candidates and chooses the cheapest falsifying experiment.
5. Implementer builds only the experiment/prototype if code is needed.
6. Verifier runs the experiment or records why it cannot be run.
7. Arbiter reports what survived, what failed, and what remains unknown.

Default roles:

```text
Orchestrator -> Scout -> Skeptic -> Planner -> Implementer -> Verifier -> Arbiter
```
